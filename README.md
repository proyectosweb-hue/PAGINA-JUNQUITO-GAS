# Página Junquito Gas

Sitio informativo de Junquito Gas (React + Vite + Tailwind).

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

Desplegado en Vercel. `vercel.json` redirige todas las rutas a `index.html` para que funcionen las rutas de React Router (`/solicitar`, `/contacto`, etc.) al recargar la página.
